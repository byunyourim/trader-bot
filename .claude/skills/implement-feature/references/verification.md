# 검증 참고

## 실행 순서 (전부 통과 필수)

```bash
# 1. 관련 테스트만 먼저
npm test -- path/to/test

# 2. 빌드 (타입 오류 포함 전체 컴파일) — 반드시 실행
npm run build

# 3. 전체 테스트 — 기존 회귀 없는지 확인
npm test
```

빌드 실패 = 작업 미완료. 원인 수정 후 재시도한다.

## 사이드 이펙트 체크리스트

- [ ] 수정한 파일을 import하는 모든 모듈 확인했는가
- [ ] 변경한 함수/타입의 시그니처가 유지되는가 (바뀌었다면 사용처 전부 수정했는가)
- [ ] 공유 유틸/서비스 변경 시 다른 기능에 영향 없는가
- [ ] 기존 테스트가 전부 통과하는가 (회귀 없음)

## 테스트 커버리지 체크리스트

- [ ] 새로 추가한 로직에 대응하는 테스트가 존재하는가
- [ ] 기존 커버리지 대비 감소가 없는가
- [ ] happy path, failure path, edge case를 각각 커버했는가

## 완료 기준 체크리스트

- [ ] 요청 기능이 동작하는가
- [ ] 관련 없는 동작이 바뀌지 않았는가
- [ ] 기존 패턴을 따랐는가
- [ ] 권한/보안 영향이 있으면 확인했는가
- [ ] `npm run build` 성공했는가
- [ ] `npm test` 전체 통과했는가
- [ ] 남은 리스크를 결과에 적었는가
