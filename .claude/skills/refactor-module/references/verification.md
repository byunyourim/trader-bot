# 리팩토링 검증

## 실행 순서 (전부 통과 필수)

```bash
# 1. 빌드 — 타입 오류·컴파일 오류 전체 확인
npm run build

# 2. 전체 테스트 — 동작 변경 없음 확인
npm test
```

빌드 실패 = 리팩토링 미완료. 원인 수정 후 재시도한다.

## 사이드 이펙트 체크리스트

- [ ] 수정 대상 모듈을 import하는 모든 파일 확인했는가
- [ ] export 함수·타입의 이름·시그니처가 유지되는가
- [ ] 이름/시그니처를 바꿨다면 모든 사용처를 함께 수정했는가
- [ ] 기존 테스트가 전부 통과하는가 (동작 변경 없음 증거)

## 완료 기준

리팩토링 후 다음 중 하나 이상이 실측으로 개선되어야 한다:

- 중복 코드 감소
- 복잡도(함수 길이/조건 depth) 감소
- 이름 명확성 증가
- 책임 분리
- 테스트 용이성 증가
